# AGENTS.md — Urbn video studio

This repository produces **brand video content for Urbn** (urbn: digital infrastructure for housing in Nigeria): a founder film, thumbnails, and campaign teasers. Everything is generated by Python scripts (PIL + numpy + ffmpeg), so every frame and sound is reproducible from code.

**Before you change anything visual or audible, read the design memory.** It records the brand rules, the decisions reviewers already made, and the mistakes not to repeat.

## Golden rules

1. **Brand first.** Use only the brand palette and type (see BRAND.md). Never rotate, flip, recolour or add effects to the logo.
2. **Vertical, safe-zone aware.** Deliverables are 1080×1920. All text and key graphics stay inside the Instagram safe zone (LAYOUT.md).
3. **Founder framing is locked.** There are only two framings, with the eyes at the same height in every shot (LAYOUT.md). Never reintroduce headroom.
4. **Hook on a face.** Videos open on a human face, with a topic kicker from frame 1. No dead air at the start.
5. **Captions:** one style, one position, single lines, hand-set breaks.
6. **Music must intrigue, not soothe.** Reviewers rejected "chill". Voice always sits clearly above the music.
7. **Every visual earns its place.** It must explain, reinforce the brand or keep attention. No random effects and no generic "startup ad" flash.
8. **Reproducible.** Change the scripts, then re-render. Don't patch output files by hand. Keep the timing tables in code (`TIMELINE`, `CAPTIONS`, `SHOTS`, `WARP`, `TAKES`).
9. **QA before you ship:** contact sheet with the safe-zone overlay, loudness check (−14 LUFS, −1 dBTP), and a spot-check of A/V sync (PIPELINE.md).
10. **Log it.** When a reviewer gives feedback or you make a design decision, add an entry to `docs/memory/FEEDBACK_LOG.md`. Update `PROJECTS.md` status.

## Quick commands

```bash
python3 edit/render.py --still 44.3 /tmp/f.png     # one frame of the founder film (source time)
python3 ibadan/animate.py --still 12.0 /tmp/f.png  # one frame of the teaser (output time)
```
Full rebuild steps: see `docs/PIPELINE.md`.
